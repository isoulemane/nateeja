# My Terraform Project

This repository contains Terraform configurations for managing infrastructure.

## Files Included
- `main.tf`: Main Terraform configuration file.
- `provider.tf`: Terraform provider configuration.
- `outputs.tf`: Output definitions for Terraform.

## How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com/isoulemane/nateeja.git

   terraform init

   terraform validate
   terraform plan
   terraform apply
   last do not forget to run terraform destroy
